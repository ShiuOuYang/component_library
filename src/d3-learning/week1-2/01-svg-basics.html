📐 SVG 基礎練習

學習目標：熟悉 SVG 基本形狀、屬性，以及如何在 HTML 中使用 SVG。 這是學習 D3.js 的第一步，因為 D3 本質上是在操作 SVG 元素。

1️⃣ 基本形狀 (Basic Shapes)

SVG 提供了多種基本形狀元素，每種都有特定的屬性來控制其外觀。

💡 關鍵屬性：
• fill: 填充顏色
• stroke: 邊框顏色
• stroke-width: 邊框寬度
• stroke-linecap: 線條端點樣式 (butt, round, square)
• stroke-linejoin: 線條轉角樣式 (miter, round, bevel)

2️⃣ 透明度與進階樣式

學習如何使用 opacity、fill-opacity、stroke-opacity 來控制元素的透明度。

🎯 練習任務：
1. 在上方 SVG 中添加一個重疊的圓形，使用不同的透明度
2. 實驗不同的 stroke-width 值，觀察效果

3️⃣ Path 路徑基礎

Path 是 SVG 中最強大的元素，可以繪製任何形狀。D3 會大量使用 path 來繪製折線圖、面積圖等。

💡 Path 指令速查：
• M x y: 移動到 (x, y)
• L x y: 畫直線到 (x, y)
• H x: 水平線到 x
• V y: 垂直線到 y
• C x1 y1, x2 y2, x y: 三次貝茲曲線
• Z: 關閉路徑 (回到起點)
🎯 挑戰任務：
1. 使用 path 繪製一個五角星
2. 使用 C 指令繪製一個波浪線
3. 結合 M, L, C 指令繪製一個簡單的圖標 (例如：心形、箭頭)

4️⃣ 文字元素 (Text)

在資料視覺化中，標籤和註解非常重要。學習如何精確控制文字的位置和樣式。

💡 文字屬性速查：
• x, y: 文字位置
• text-anchor: 水平對齊 (start, middle, end)
• dominant-baseline: 垂直對齊 (hanging, middle, baseline)
• font-size, font-weight, font-family: 字體樣式
• tspan: 用於多行文字或部分樣式變更

5️⃣ 群組元素 (Group)

使用 <g> 元素來組織相關的圖形，可以統一套用樣式和變換。這是 D3 中非常重要的概念。

💡 群組的優勢：
• 統一套用樣式 (fill, stroke 等)
• 統一套用變換 (transform)
• 便於管理和組織 SVG 結構
• 在 D3 中，經常用 <g> 來組織圖表的各個部分 (軸、圖例、資料點等)
🎯 實戰練習：創建一個長條圖單元
使用 <g> 包裹：
1. 一個 <rect> 作為長條
2. 一個 <text> 作為數值標籤
3. 一個 <text> 作為類別標籤
然後嘗試使用 transform="translate()" 移動整個單元
