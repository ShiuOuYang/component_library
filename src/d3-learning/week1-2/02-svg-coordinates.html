📍 SVG 座標系統與變換

學習目標：深入理解 SVG 的座標系統、transform 屬性，以及 viewBox 的應用。 這些概念是掌握 D3.js 的關鍵基礎。

1️⃣ SVG 座標系統基礎

SVG 的座標系統與數學座標系統不同：
• 原點 (0, 0) 在左上角
• X 軸向右遞增
• Y 軸向下遞增 (注意：是向下！)

💡 關鍵觀念：
• SVG 座標從左上角 (0,0) 開始
• Y 軸向下遞增 (與數學座標系統相反！)
• 每個 SVG 元素都有自己的座標空間
• 在 D3 繪圖時，經常需要「翻轉」Y 軸來符合數據邏輯
💡 網格背景原理解析：
這段程式碼展示了如何製作重複的網格背景：
1. <defs>: 定義區，裡面的圖形不會直接顯示。
2. <pattern>: 定義一塊 50x50 的「磁磚」。
3. <path>: 在磁磚內畫線 (上邊框與左邊框)。
4. <rect fill="url(#grid)">: 畫一個大矩形，並用定義好的磁磚填滿它。 
<defs>
  <pattern id="grid" width="50" height="50" patternUnits="userSpaceOnUse">
    <path d="M 50 0 L 0 0 0 50" fill="none" class="grid-line"/>
  </pattern>
</defs>
<rect width="600" height="400" fill="url(#grid)"/>

2️⃣ Transform: Translate (位移)

transform="translate(x, y)" 可以移動元素的位置，而不需要修改元素本身的座標。 這在 D3 中非常常用，特別是在建立圖表的邊界 (margin) 時。

💡 為什麼使用 translate？
• 保持元素原始座標不變，便於重複使用
• 可以對整個 <g> 群組進行位移
• 在 D3 中，常用 translate 來設定圖表的 margin

範例：
<g transform="translate(60, 20)">
  <rect x="0" y="0" width="100" height="50"/>
</g>
實際顯示位置：(60, 20)

3️⃣ Transform: Rotate (旋轉)

transform="rotate(angle)" 或 transform="rotate(angle, cx, cy)" 可以旋轉元素。

💡 Rotate 用法：
• transform="rotate(angle)": 預設繞原點 (0,0) 旋轉
• transform="rotate(angle, cx, cy)": 繞指定點 (cx, cy) 旋轉
• 角度單位是「度」，正值為順時針
• 常用於：X 軸標籤旋轉、圓形圖表 (pie chart)、放射圖 (radar chart)
🎯 練習任務：
1. 創建一個圓形圖表的扇形 (使用 path 和 rotate)
2. 製作一個指南針圖案 (使用多個 rotate)

4️⃣ Transform: Scale (縮放)

transform="scale(s)" 或 transform="scale(sx, sy)" 可以縮放元素。

💡 Scale 注意事項：
• scale(s): X 和 Y 同時縮放 s 倍
• scale(sx, sy): X 縮放 sx 倍，Y 縮放 sy 倍
• 縮放會影響所有屬性，包括 stroke-width
• 縮放中心點預設是 (0, 0)，通常需要配合 translate 使用

5️⃣ 組合多個變換

可以在同一個 transform 屬性中組合多個變換，執行順序從右到左。

⚠️ 重要觀念：變換順序
• transform="translate(50,0) rotate(45)": 先位移 50px，再原地旋轉 45°
• transform="rotate(45) translate(50,0)": 先旋轉 45°，再沿旋轉後的軸位移
• 變換從右到左執行 (與直覺相反！)
• 在 D3 中，常見模式是：translate → rotate → scale

6️⃣ ViewBox：響應式 SVG 的關鍵

viewBox="minX minY width height" 定義了 SVG 的「視窗」，可以實現響應式設計和縮放。

沒有 viewBox (固定大小)

使用 viewBox (自動縮放)

放大局部 (viewBox zoom)

視窗平移 (viewBox pan)

💡 ViewBox 語法：
viewBox="minX minY width height"
• minX, minY: 視窗左上角的座標
• width, height: 視窗的寬高

實用場景：
• 響應式圖表：定義固定的 viewBox，讓 SVG 自動縮放
• 縮放功能：改變 viewBox 的 width/height 來實現 zoom in/out
• 平移功能：改變 viewBox 的 minX/minY 來實現 pan
• D3 的 zoom 行為就是基於 viewBox 或 transform 實現的
🎯 進階挑戰：
1. 創建一個 SVG 圖表，使用 viewBox 使其在不同螢幕尺寸下保持比例
2. 用 JavaScript 動態修改 viewBox，實現簡單的縮放效果

7️⃣ D3 Margin Convention (圖表邊界慣例)

這是 D3 社群的標準做法，用於在圖表周圍留出空間給座標軸和標籤。

💡 Margin Convention 程式碼模板：
// 1. 定義尺寸和邊界
const margin = { top: 60, right: 60, bottom: 40, left: 80 };
const width = 800 - margin.left - margin.right;
const height = 400 - margin.top - margin.bottom;

// 2. 創建 SVG
const svg = d3.select("#chart")
  .append("svg")
  .attr("width", width + margin.left + margin.right)
  .attr("height", height + margin.top + margin.bottom);

// 3. 創建繪圖群組 (應用 margin)
const g = svg.append("g")
  .attr("transform", `translate(${margin.left}, ${margin.top})`);

// 4. 在 g 內繪製圖表元素
g.append("rect")
  .attr("x", 0)
  .attr("y", 0)
  .attr("width", width)
  .attr("height", height);
