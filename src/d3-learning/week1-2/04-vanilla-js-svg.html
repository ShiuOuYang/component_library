🎮 Vanilla JavaScript 操作 SVG

學習目標：使用原生 JavaScript 動態創建和操作 SVG 元素。 這是理解 D3.js 核心機制的關鍵一步！
重要觀念：D3 本質上就是一個更強大的 DOM 操作工具，理解原生 JS 如何操作 SVG， 就能理解 D3 在背後做了什麼。

1️⃣ 創建 SVG 元素的正確方式

⚠️ 重要：SVG 元素屬於 XML 命名空間，不能用 document.createElement()， 必須使用 document.createElementNS()！

💡 核心程式碼：
// SVG 命名空間
const svgNS = "http://www.w3.org/2000/svg";

// 創建 SVG 容器
const svg = document.createElementNS(svgNS, "svg");
svg.setAttribute("width", "600");
svg.setAttribute("height", "200");

// 創建圓形
const circle = document.createElementNS(svgNS, "circle");
circle.setAttribute("cx", "100");
circle.setAttribute("cy", "100");
circle.setAttribute("r", "50");
circle.setAttribute("fill", "#4CAF50");

// 添加到 SVG
svg.appendChild(circle);
document.getElementById("chart1").appendChild(svg);

2️⃣ 動態生成長條圖

使用 JavaScript 陣列來生成長條圖。這是 D3 data binding 的基礎概念。

💡 核心概念：
• 使用 Array.forEach() 遍歷數據
• 為每個數據點創建對應的 SVG 元素
• 計算位置和大小 (這就是 D3 Scales 的工作)
• 動態更新時，清除舊元素，創建新元素

3️⃣ 添加互動效果

為 SVG 元素添加事件監聽器，實現滑鼠互動。

提示： 點擊或懸停在長條上查看資訊
💡 事件監聽：
// 添加滑鼠事件
rect.addEventListener('mouseover', function(event) {
  this.setAttribute('fill', '#FF9800');
  showTooltip(event, data);
});

rect.addEventListener('mouseout', function() {
  this.setAttribute('fill', originalColor);
  hideTooltip();
});

rect.addEventListener('click', function() {
  console.log('Clicked:', data);
});

4️⃣ 動畫與過渡效果

使用 CSS transitions 和 JavaScript 實現平滑動畫。

💡 動畫技巧：
• 使用 CSS transitions 實現平滑過渡
• 使用 setTimeout 控制動畫時序
• 使用 requestAnimationFrame 實現高效能動畫
• 在 D3 中，這些由 d3.transition() 自動處理

5️⃣ 完整的資料驅動圖表

結合所有概念，創建一個完整的動態長條圖，包含座標軸、標籤和互動。

💡 資料驅動開發流程：
1. 定義數據結構
2. 創建 SVG 容器和座標系統
3. 根據數據創建視覺元素
4. 添加互動和動畫
5. 實現數據更新機制

這就是 D3 的核心哲學：Data-Driven Documents！

🎯 進階挑戰

挑戰 1：實現 Enter-Update-Exit 模式
當數據更新時，不是重新繪製所有元素，而是：
• Enter: 為新數據創建元素
• Update: 更新現有元素
• Exit: 移除多餘的元素

挑戰 2：創建一個折線圖
使用 SVG <path> 元素和 JavaScript 計算路徑數據。

挑戰 3：實現拖曳功能
讓使用者可以拖曳長條來改變數值。

挑戰 4：響應式圖表
使用 ResizeObserver 監聽容器大小變化，自動重繪圖表。
